# 🛡️ Cyber Toolkit v5.0

A Python-based cybersecurity toolkit with a simple and modern desktop interface.

## ✨ Features

- 🔐 Password Generator
- 📊 Password Strength Checker
- #️⃣ SHA-256 Hash Generator
- 📋 Copy Generated Password
- 💾 View Saved Passwords
- 🗑️ Delete Saved Passwords
- 🖥️ Desktop GUI
- 📦 Standalone Windows executable
